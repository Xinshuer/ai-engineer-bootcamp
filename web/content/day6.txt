@@ concept
title: async / await：等网络的时候不卡住
--- body
网络请求要等。TypeScript 用 **Promise** 表示「将来才有的结果」：

```ts
async function ask(prompt: string): Promise<string> {
  const res = await fetch(URL, ...);   // 在这里等，等到了再往下
  const data = await res.json();       // json() 也要等
  return data.choices[0].message.content;
}
```

- 函数前加 `async`，返回类型写成 `Promise<真正的类型>`
- 在 async 函数里用 `await` 等一个 Promise 完成
- **最常见的 bug：忘了 await**，拿到的是一个还没完成的 Promise，而不是结果
- 调用 async 函数也要 `await`：`const text = await ask("hi");`
--- code
function wait(ms: number): Promise<void> {
  return new Promise((resolve) => setTimeout(resolve, ms));
}

async function review(id: string): Promise<string> {
  console.log("start", id);
  await wait(10);
  return `done ${id}`;
}

async function main() {
  const r = await review("8.1");
  console.log(r);
  const p = review("4.2");
  console.log("without await:", p);
  console.log("after await:", await p);
}
main();

title: fetch：TypeScript 里的 requests.post
--- body
```ts
const res = await fetch("https://api.deepseek.com/v1/chat/completions", {
  method: "POST",
  headers: { Authorization: `Bearer ${process.env.DEEPSEEK_API_KEY}`, "Content-Type": "application/json" },

```

和 Python 的三个不同：要写 `method: "POST"`；请求体要自己 `JSON.stringify`；`res.json()` 要 await。

`process.env.DEEPSEEK_API_KEY` 读环境变量，和 `os.getenv` 一样。本页连的是模拟服务器，本机连的就是真的。

思考模式和第 4 天一样：默认开着，思考过程在 `message.reasoning_content`，思考 token 按输出计费。审查条款的请求加 `thinking: { type: "disabled" }` 关掉它（更快、更便宜、`temperature` 才起作用）。
--- code
async function main() {
  const res = await fetch("https://api.deepseek.com/v1/chat/completions", {
    method: "POST",
    headers: { Authorization: `Bearer ${process.env.DEEPSEEK_API_KEY}`, "Content-Type": "application/json" },
    body: JSON.stringify({ model: "deepseek-flash", messages: [{ role: "user", content: "Say hello" }] }),
  });
  console.log(res.status, res.ok);
  const data = await res.json();
  console.log(data.choices[0].message.content);
  console.log(data.usage.total_tokens, "reasoning:", data.usage.completion_tokens_details.reasoning_tokens);

  const off = await fetch("https://api.deepseek.com/v1/chat/completions", {
    method: "POST",
    headers: { Authorization: `Bearer ${process.env.DEEPSEEK_API_KEY}`, "Content-Type": "application/json" },
    body: JSON.stringify({ model: "deepseek-flash", messages: [{ role: "user", content: "Say hello" }], thinking: { type: "disabled" } }),
  });
  const offData = await off.json();
  // 关掉思考：没有 reasoning_content，token 少了一大截（关掉时 completion_tokens_details 不一定返回，别直接读它）
  console.log(offData.usage.total_tokens);

@@ concept
title: try / catch / throw
--- body
```ts
try {
  const data = JSON.parse(raw);
} catch (e) {
  console.log("bad json:", e instanceof Error ? e.message : String(e));
}
```

- Python 的 `except` → `catch`；`raise ValueError("...")` → `throw new Error("...")`
- TypeScript 里 `catch (e)` 的 `e` 类型是 `unknown`（谁都可能被 throw），用之前先判断 `e instanceof Error`
- async 函数里 throw 的错误，调用方 `await` 时会在 try/catch 里接住
--- code
function parseRisk(text: string): string {
  const risk = text.trim().toLowerCase();
  if (!["low", "medium", "high"].includes(risk)) {
    throw new Error(`unknown risk: ${text}`);
  }
  return risk;
}
console.log(parseRisk(" HIGH "));
try {
  parseRisk("urgent");
} catch (e) {
  console.log("caught:", e instanceof Error ? e.message : String(e));
}
try {
  JSON.parse("{oops");
} catch (e) {
  console.log("bad json:", e instanceof Error ? e.name : "?");
}

@@ concept
title: Zod：TypeScript 的 Pydantic
--- body
```ts
import { z } from "zod";

const VerdictSchema = z.object({
  clause_id: z.string(),
  verdict: z.enum(["accept", "flag", "redline"]),
  confidence: z.number().default(0.5),
});
```

- `z.enum([...])` 就是 `Literal[...]`；`z.object({...})` 就是 `BaseModel`
- `Schema.parse(data)`：合法就返回数据，不合法 **throw**
- `Schema.safeParse(data)`：不 throw，返回 `{ success: true, data }` 或 `{ success: false, error }`，错误在 `error.issues`
- 注意 Zod 校验的是**对象**，模型给的文字要先 `JSON.parse`
--- code
import { z } from "zod";

const VerdictSchema = z.object({
  clause_id: z.string(),
  verdict: z.enum(["accept", "flag", "redline"]),
  confidence: z.number().default(0.5),
});

console.log(VerdictSchema.parse({ clause_id: "8.1", verdict: "flag" }));
const bad = VerdictSchema.safeParse({ clause_id: "8.1", verdict: "HIGH" });
if (!bad.success) {
  console.log(bad.error.issues[0].path, bad.error.issues[0].message);
}

@@ concept
title: z.infer：一份定义，两处使用
--- body
Pydantic 的类本身就是类型。Zod 的 schema 是一个**值**，要用 `z.infer` 从它得到**类型**：

```ts
type Verdict = z.infer<typeof VerdictSchema>;
// { clause_id: string; verdict: "accept" | "flag" | "redline"; confidence: number }
```

这样运行时的校验（schema）和编译时的类型（type）永远一致，不用写两遍。Clause Check 里 Pydantic 同时生成给模型看的 JSON Schema，也是同一个思路。
--- code
import { z } from "zod";

const VerdictSchema = z.object({
  clause_id: z.string(),
  verdict: z.enum(["accept", "flag", "redline"]),
});
type Verdict = z.infer<typeof VerdictSchema>;

function describe(v: Verdict): string {
  return `${v.clause_id}: ${v.verdict}`;
}
const v: Verdict = VerdictSchema.parse(JSON.parse('{"clause_id": "8.1", "verdict": "redline"}'));
console.log(describe(v));

@@ concept
title: import / export 和 Mastra 长什么样
--- body
真实项目里代码分在多个文件：一个文件 `export function classify(...)`，另一个文件 `import { classify } from "./review"`。本页每题只有一个文件，但会用到 `import { z } from "zod"`。

Mastra 的工具定义大致是这个形状（示意，具体写法以 mastra.ai 官方文档为准）：

```ts
const lookupPlaybook = createTool({
  id: "lookup_playbook",
  description: "Return the customer's rule for one topic. Call before deciding.",
  inputSchema: z.object({ topic: z.enum(["payment", "liability_cap"]) }),
  execute: async (...) => { ... },
});
```

你已经能读懂它的每一部分：Zod 定义参数（等于 Pydantic）、description 写「何时用」、execute 是 async 函数。Python 的 `@tool + Pydantic` 和 Mastra 的 `createTool + Zod` 是同一个概念。面试时说：「概念一样，我在 Python 里做过的每件事在 Mastra 里都有对应物。」
--- code
import { z } from "zod";

const ToolInput = z.object({ topic: z.enum(["payment", "liability_cap"]) });
type ToolInput = z.infer<typeof ToolInput>;

async function execute(input: ToolInput): Promise<string> {
  return `rule for ${input.topic}`;
}

async function main() {
  const raw = JSON.parse('{"topic": "payment"}');
  console.log(await execute(ToolInput.parse(raw)));
  console.log(ToolInput.safeParse({ topic: "gdpr" }).success);
}
main();

--- solution
const API_URL = "https://api.deepseek.com/v1/chat/completions";
const HEADERS = { Authorization: `Bearer ${process.env.DEEPSEEK_API_KEY}` };

async function callApi(body: object): Promise<any> {
  const res = await fetch(API_URL, { method: "POST", headers: HEADERS, body: JSON.stringify(body) });
  const data = await res.json();
  if (!res.ok) {
    throw new Error(`API error ${res.status}: ${data.error.message}`);
  }
  return data;
}

--- solution
const API_URL = "https://api.deepseek.com/v1/chat/completions";
const HEADERS = { Authorization: `Bearer ${process.env.DEEPSEEK_API_KEY}` };
const RETRYABLE = [429, 500, 503];

async function askWithRetry(prompt: string, maxAttempts = 3): Promise<string> {
  const body = JSON.stringify({ model: "deepseek-flash", messages: [{ role: "user", content: prompt }] });
  for (let attempt = 1; attempt <= maxAttempts; attempt++) {
    const res = await fetch(API_URL, { method: "POST", headers: HEADERS, body });
    if (res.status === 200) {
      const data = await res.json();
      return data.choices[0].message.content;
    }
    if (!RETRYABLE.includes(res.status)) {
      throw new Error(`not retryable: ${res.status}`);
    }
  }
  throw new Error(`gave up after ${maxAttempts} attempts`);
}
--- tests

  const text = await askWithRetry("hi");
  return [text, MOCK.calls.length];
}, ["Mock reply: hi", 3]);
expectAsync("一直 503：throw，且只请求 3 次", async () => {
  MOCK.reset(); MOCK.failNext(503, 5);
  try { await askWithRetry("hi"); return "没有报错"; } catch { return MOCK.calls.length; }
}, 3);
expectAsync("401 不重试", async () => {
  MOCK.reset(); MOCK.failNext(401);
  try { await askWithRetry("hi"); return "没有报错"; } catch { return MOCK.calls.length; }
}, 1);
--- hints

function parseVerdict(raw: string): Verdict | string {

    data = JSON.parse(raw);

  const res = await fetch(API_URL, { method: "POST", headers: HEADERS, body: JSON.stringify({ model: "deepseek-flash", messages: [{ role: "user", content: text }], response_format: { type: "json_object" }, thinking: { type: "disabled" } }) });

async function passRate(text: string, expected: string, n: number): Promise<number> {
  let hits = 0;
  for (let i = 0; i < n; i++) {
    const v = await classify(text);
    if (v.verdict === expected) {
      hits += 1;
    }
  }
  return hits / n;
}

  topic: z.string(),

function loadRule(raw: string): Rule | null {

async function countTokens(prompts: string[]): Promise<number> {
