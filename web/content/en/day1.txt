@@ concept project
title: Meet the project: Clause Check
--- body
Almost every exercise in this course comes from one real project: **Clause Check**, a small program that helps people review contracts. It works in this order:

1. Read a contract and cut it into numbered **clauses**. Each clause has a number (`clause_id`, for example `"8.1"`) and a heading (`heading`, for example `"Cap on Liability"`)
2. Send each clause to a **large language model** (this course uses DeepSeek) and have it check the clause against the company's review rules (the **playbook**). The model gives a **verdict**, one of three:
   - `accept`: fine, accept it
   - `flag`: risky, mark it for a person to look at
   - `redline`: must be rewritten; the model suggests new wording
3. Each clause also gets a **risk** level: `high` / `medium` / `low`
4. Collect the results for all clauses into a report for the person reviewing the contract

Every exercise is one small piece of this pipeline. The **Background** above each exercise says which step it belongs to and why it is needed; **Knowledge cards used** opens the matching card so you can review it.

You don't need to remember these words now. Come back to this card whenever you forget one. (Local tasks on your own computer assume the project lives in `G:\Contract Clause Reviewer`; use your own folder instead.)

- Separate several values in `print` with commas; the output puts one space between them

@@ concept
title: Variables and types
--- body
`=` means "put the value on the right into the name on the left". It is not the equals sign from math. After that, the name gives you the value back.

The most common types:

- `str` string: `"8.1"`
- `int` whole number: `3`
- `float` decimal number: `0.82`
- `bool` true or false: `True` / `False` (capital first letter)
- `None`: nothing at all

`type(x)` shows the type. A variable can be assigned again: `page = page + 1` computes a new value from the old one and puts it back.
--- code
clause_id = "8.1"
page = 3
ratio = 0.82
is_risky = True
print(clause_id, page, ratio, is_risky)
print(type(clause_id), type(page))
page = page + 1
print(page)

@@ concept
title: Strings
--- body
- **f-string**: inside `f"..."`, `{variable}` is replaced by its value. This is the usual way to build text
- Common methods: `.strip()` removes spaces at both ends, `.lower()` / `.upper()` change case, `.replace(a, b)` replaces text, `.split(".")` cuts at a separator, `.startswith(x)` checks the beginning
- `"x" in s` checks whether s contains x, `len(s)` is the length
- Indexes: `s[0]` is the first character, `s[-1]` the last; the slice `s[0:3]` takes characters 0, 1 and 2

String methods **never change the original string**. They return a new one, so keep the result in a variable.
--- code
heading = "  Cap on Liability  "
clean = heading.strip()
print(f"[{clean}]")
print(clean.lower(), clean.upper())
print(clean.replace("Cap", "Limit"))
print("8.1".split("."))
print("Liability" in clean, len(clean))
print(clean[0], clean[-1], clean[0:3])

@@ concept
title: Lists
--- body
`[...]` holds several values in order.

- Indexes start at **0**: `ids[0]` is the first, `ids[-1]` the last
- `len(ids)` is how many there are, `ids.append(x)` adds x at the end
- The slice `ids[1:3]` takes indexes 1 and 2 (not 3)
- `x in ids` checks whether x is in the list

Unlike strings, `append` **changes the list itself**.
--- code
ids = ["3.1", "4.2", "8.1"]
print(ids[0], ids[-1], len(ids))
ids.append("12")
print(ids)
print(ids[1:3])
print("8.1" in ids, "9.9" in ids)

@@ concept
title: if / elif / else
--- body
- Comparisons: `==` equal, `!=` not equal, `<` `>` `<=` `>=`
- Combining: `and` both are true, `or` at least one is true, `not` flips it
- Don't forget the colon `:` at the end
- **Indentation (4 spaces)** says "these lines belong to the if above". Python uses indentation to know where a block starts and ends

`elif` means "else if", and you can have many; `else` catches everything left, and is optional.
--- code
risk = "high"
verdict = "accept"
if risk == "high":
    print("Look at this one first")
elif risk == "medium":
    print("Look when you have time")
else:
    print("Can skip")
if risk == "high" and verdict == "accept":
    print("High risk but accepted? Worth a second look")

@@ concept
title: Functions: def and return
--- body
Almost every exercise is "write a function". Remember the shape:

```python
def function_name(param1, param2):
    ...compute...
    return result
```

Call it as `function_name(value1, value2)` and you get back what it `return`s.

**return is not print**: `print` only shows something on the screen; `return` hands the result to the code that called the function. The tests check the `return` value, so a function that only prints will never pass. A function stops at `return`; lines after it do not run.
--- code
def describe(clause_id, heading):
    return f"{clause_id} {heading}"

text = describe("8.1", "Cap on Liability")
print(text)
print(describe("4.2", "Automatic Renewal"))

@@ concept
title: Reading errors: start from the last line
error_demo: yes
--- body
Errors are not scary: they tell you what went wrong. How to read one:

1. **Read the last line first**: the error type and the reason
2. Then the `File "main.py", line N` above it: which line
3. Go to that line and compare

The three most common:

- `NameError: name 'x' is not defined`: the name was never defined, usually a **typo**
- `TypeError`: the wrong type, for example a string `+` a number
- `SyntaxError` / `IndentationError`: the code is written wrongly or indented wrongly, for example a missing colon

Run the code below, read the error, then fix it.
--- code
