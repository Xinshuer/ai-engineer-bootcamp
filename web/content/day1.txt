@@ concept
title: 代码怎么跑：print 和注释
--- body
代码从上到下一行一行执行。`print(...)` 把括号里的东西显示在输出区，是你观察程序的眼睛。

- 文字（字符串）要用引号包起来：`"Hello"`
- `#` 后面是注释，只给人看，不会执行
- `print` 里用逗号隔开多个值，输出时中间自动加一个空格

改一改下面的代码再点「运行」，这是今天最重要的习惯：**写两三行就运行一次**。
--- code
# 这是注释，不会执行
print("Hello, Clause Check")
print("8.1", "Cap on Liability")
print(1 + 2)

@@ concept
title: 变量和类型
--- body
`=` 的意思是「把右边的值放进左边的名字里」，不是数学里的等于。之后用这个名字就能拿到那个值。

最常见的几种类型：

- `str` 字符串：`"8.1"`
- `int` 整数：`3`
- `float` 小数：`0.82`
- `bool` 真假：`True` / `False`（首字母大写）
- `None`：什么都没有

`type(x)` 可以查看类型。变量可以被重新赋值：`page = page + 1` 是先用旧值算出新值，再放回去。
--- code
clause_id = "8.1"
page = 3
ratio = 0.82
is_risky = True
print(clause_id, page, ratio, is_risky)
print(type(clause_id), type(page))
page = page + 1
print(page)

@@ concept
title: 字符串
--- body
- **f-string**：`f"..."` 里的 `{变量}` 会被替换成它的值，这是拼文字最常用的写法
- 常用方法：`.strip()` 去首尾空白，`.lower()` / `.upper()` 转大小写，`.replace(a, b)` 替换，`.split(".")` 按分隔符切开，`.startswith(x)` 是否以 x 开头
- `"x" in s` 判断是否包含，`len(s)` 长度
- 下标：`s[0]` 第一个字符，`s[-1]` 最后一个；切片 `s[0:3]` 取第 0、1、2 个

字符串方法**不会改变原来的字符串**，而是返回一个新的，所以要用变量接住结果。
--- code
heading = "  Cap on Liability  "
clean = heading.strip()
print(f"[{clean}]")
print(clean.lower(), clean.upper())
print(clean.replace("Cap", "Limit"))
print("8.1".split("."))
print("Liability" in clean, len(clean))
print(clean[0], clean[-1], clean[0:3])

@@ concept
title: 列表
--- body
`[...]` 按顺序装多个值。

- 下标从 **0** 开始：`ids[0]` 是第一个，`ids[-1]` 是最后一个
- `len(ids)` 个数，`ids.append(x)` 在末尾添加
- 切片 `ids[1:3]` 取下标 1 和 2（不含 3）
- `x in ids` 判断是否在列表里

和字符串不同，`append` 会**直接修改**原来的列表。
--- code
ids = ["3.1", "4.2", "8.1"]
print(ids[0], ids[-1], len(ids))
ids.append("12")
print(ids)
print(ids[1:3])
print("8.1" in ids, "9.9" in ids)

@@ concept
title: if / elif / else
--- body
- 比较：`==` 等于，`!=` 不等于，`<` `>` `<=` `>=`
- 组合：`and` 两边都成立，`or` 任一成立，`not` 取反
- 结尾的冒号 `:` 不能丢
- **缩进（4 个空格）**表示「这几行属于上面那个 if」，Python 靠缩进判断代码块

`elif` 是「否则如果」，可以有很多个；`else` 是最后的兜底，可以没有。
--- code
risk = "high"
verdict = "accept"
if risk == "high":
    print("先看这条")
elif risk == "medium":
    print("有空再看")
else:
    print("可以跳过")
if risk == "high" and verdict == "accept":
    print("高风险却被放过？值得复查")

@@ concept
title: 函数：def 和 return
--- body
练习题几乎都是「写一个函数」。先记住形状：

```python
def 函数名(参数1, 参数2):
    ...计算...
    return 结果
```

调用时写 `函数名(值1, 值2)`，得到 `return` 回来的结果。

**return 和 print 不一样**：`print` 只是显示在屏幕上；`return` 才是把结果交给调用它的代码。测试检查的是 `return` 的值，所以只 `print` 不 `return` 的函数一定过不了测试。函数执行到 `return` 就结束，后面的行不再运行。
--- code
def describe(clause_id, heading):
    return f"{clause_id} {heading}"

text = describe("8.1", "Cap on Liability")
print(text)
print(describe("4.2", "Automatic Renewal"))

title: 读报错：从最后一行往上看
error_demo: yes
--- body
报错不可怕，它是在告诉你哪里错了。读法：

1. **先看最后一行**：错误类型和原因
2. 再看上面的 `File "main.py", line N`：错在第几行
3. 回到那一行对照

最常见的三种：

- `NameError: name 'x' is not defined`：名字没定义过，多半是**拼错了**
- `TypeError`：类型不对，比如字符串 `+` 数字
- `SyntaxError` / `IndentationError`：写法或缩进错，比如漏了冒号

运行下面的代码，看看报错，然后修好它。
--- code
clause_id = "8.1"
print("Clause " + clause_id)
print(clause_idd)
