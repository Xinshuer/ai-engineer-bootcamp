title: 读写文件：open、with、encoding
--- body
程序一结束，变量就没了。想把结果（报告、日志）留下来，就要写进**文件**：

```python
with open("notes.txt", "w", encoding="utf-8") as f:
    f.write("8.1 flag\n")
```

- `with` 块结束时自动关闭文件，中途报错也会关。所以永远用 `with`
- 模式：`"r"` 读（默认）、`"w"` 写（**先清空**原内容）、`"a"` 追加到末尾
- `f.read()` 读出整个文件；`for line in f:` 一行一行读，每行末尾带着 `"\n"`
- **永远写 `encoding="utf-8"`**。Windows 上不写时默认编码往往不是 UTF-8，遇到中文、`§`、`ö` 就乱码或报 `UnicodeDecodeError`。项目 `parse.py` 读合同时就写了它
--- code
with open("d10_log.txt", "w", encoding="utf-8") as f:
    f.write("8.1 flag\n")
    f.write("3.1 accept\n")

with open("d10_log.txt", "a", encoding="utf-8") as f:
    f.write("4.2 redline\n")

with open("d10_log.txt", encoding="utf-8") as f:
    print(repr(f.read()))

with open("d10_log.txt", encoding="utf-8") as f:
    for n, line in enumerate(f, start=1):
        print(n, line.rstrip("\n"))

title: pathlib：路径是对象
--- body
用字符串拼路径（`"data" + "/" + name`）很容易拼错。`pathlib.Path` 把路径变成一个对象：

- `Path("data") / "sample_contract.txt"`：用 `/` 拼路径。Windows 上也这么写，打印出来会变成 `data\sample_contract.txt`
- 拆开看：`.name` 文件名、`.stem` 去掉后缀的名字、`.suffix` 后缀、`.parent` 所在的文件夹
- `.with_suffix(".report.json")` 换后缀。`cli.py` 没给 `--out` 时就用它算报告路径
- `.exists()` 在不在；`.read_text(encoding="utf-8")` 和 `.write_text(文字, encoding="utf-8")` 一行读写整个文件，不用自己 `open`

本页跑在浏览器里的 Linux 风格虚拟磁盘上，所以打印出来是 `/`。
--- code
from pathlib import Path

p = Path("data") / "sample_contract.txt"
print(p, "|", p.name, "|", p.stem, "|", p.suffix, "|", p.parent)
print(p.with_suffix(".report.json"))
print(p.exists())

note = Path("d10_note.txt")
note.write_text("Clause 8.1 needs a lawyer.\n", encoding="utf-8")
print(note.exists(), repr(note.read_text(encoding="utf-8")))

title: 文件夹：mkdir、glob 和「当前目录」
--- body
- `folder.mkdir(parents=True, exist_ok=True)` 建文件夹：`parents=True` 连中间缺的上级一起建，`exist_ok=True` 已经存在也不报错。写文件之前先建它的上级：`path.parent.mkdir(...)`
- `folder.glob("*.json")` 找出匹配的文件。返回顺序没有保证，所以几乎总是写 `sorted(folder.glob("*.json"))`
- **相对路径是从「当前目录」算起的**，也就是你运行命令时所在的文件夹，而不是 .py 文件所在的文件夹。`Path.cwd()` 可以看当前目录

所以项目要在 `G:\Contract Clause Reviewer` 里运行，才找得到 `data/sample_contract.txt`。`config.py` 里的 `ROOT = Path(__file__).resolve().parent.parent` 是从代码文件的位置推出项目根目录，这样从哪里运行都不会找错。
--- code
from pathlib import Path

folder = Path("work/d10/demo")
folder.mkdir(parents=True, exist_ok=True)
for name in ["b.json", "a.json", "notes.txt"]:
    (folder / name).write_text("{}", encoding="utf-8")

print(Path.cwd())
print([p.name for p in sorted(folder.glob("*.json"))])
print([p.name for p in sorted(folder.glob("*"))])

@@ concept
title: JSON 文件：load 和 dump
--- body
第 3 天的 `json.loads` / `json.dumps` 处理的是**字符串**（s 就是 string）。读写**文件**有两种写法：

```python
with open(path, "w", encoding="utf-8") as f:
    json.dump(report, f, indent=2, ensure_ascii=False)   # 写
with open(path, encoding="utf-8") as f:
    report = json.load(f)                                # 读

report = json.loads(Path(path).read_text(encoding="utf-8"))  # playbook.py 的写法
```

- `indent=2` 让人能读；`ensure_ascii=False` 让中文原样写出，而不是变成 `\u5f8b` 这样的转义
- 经典错误：`json.dump(report, "out.json")`。第二个参数要的是**打开的文件**，传字符串会报 `AttributeError: 'str' object has no attribute 'write'`
--- code
import json
from pathlib import Path

report = {"contract": "sample_contract", "counts": {"accept": 17, "redline": 11}, "note": "需要律师看 8.1"}
path = Path("work/d10/demo/report.json")
path.parent.mkdir(parents=True, exist_ok=True)
with open(path, "w", encoding="utf-8") as f:
    json.dump(report, f, indent=2, ensure_ascii=False)

print(path.read_text(encoding="utf-8"))
with open(path, encoding="utf-8") as f:
    back = json.load(f)
print(back == report, back["counts"]["redline"])
print(json.dumps({"note": "律师"}))

title: CSV：让律师用 Excel 打开
--- body
律师不读 JSON，他们用 Excel。CSV 就是「用逗号分隔的表格文字」，`csv` 模块替你处理引号和正文里的逗号：

- 写：`writer = csv.DictWriter(f, fieldnames=[列名...])`，先 `writer.writeheader()` 写表头，再 `writer.writerows(字典列表)`
- 打开文件时加 `newline=""`，否则 Windows 上每行之间会多出一个空行
- 读：`csv.DictReader(f)`，每行是一个字典。**读回来的值全是字符串**，`"340"` 要自己 `int(...)`
- 想让 Excel 正确显示中文，编码用 `"utf-8-sig"`（文件开头多一个 BOM 标记）；读的时候也用它，否则第一个列名前会多一个看不见的字符
--- code
import csv
from pathlib import Path

rows = [
    {"clause_id": "8.1", "verdict": "redline", "tokens": 340, "rationale": "cap is not mutual, see 12"},
    {"clause_id": "3.1", "verdict": "accept", "tokens": 120, "rationale": "standard"},
]
path = Path("work/d10/demo/reviews.csv")
path.parent.mkdir(parents=True, exist_ok=True)
with open(path, "w", encoding="utf-8", newline="") as f:
    writer = csv.DictWriter(f, fieldnames=["clause_id", "verdict", "tokens", "rationale"])
    writer.writeheader()
    writer.writerows(rows)

print(path.read_text(encoding="utf-8"))
with open(path, encoding="utf-8", newline="") as f:
    back = list(csv.DictReader(f))
print(back[0])
print(back[0]["tokens"] + back[1]["tokens"], int(back[0]["tokens"]) + int(back[1]["tokens"]))

title: 命令行参数：argparse
--- body
在终端运行 `python -m clausecheck review data/sample_contract.txt --mode mock` 时，程序拿到的只是一串文字：`["review", "data/sample_contract.txt", "--mode", "mock"]`（就是 `sys.argv[1:]`）。`argparse` 把它变成有名字、有类型、有检查的参数：

```python
parser = argparse.ArgumentParser(prog="clausecheck")
parser.add_argument("path")                                  # 位置参数：必填
parser.add_argument("--out")                                 # 可选，不给就是 None
parser.add_argument("--mode", choices=["mock", "deepseek"], default="mock")
parser.add_argument("--limit", type=int)                     # 自动转成 int
parser.add_argument("--verbose", action="store_true")        # 出现就是 True
args = parser.parse_args(["data/c.txt", "--limit", "5"])
```

- 用点取值：`args.path`、`args.limit`。名字里的 `-` 会变成 `_`：`--only-risk` → `args.only_risk`
- 值不合法（不在 `choices` 里、`--limit abc`）时，argparse 打印用法和原因，然后以退出码 2 结束
- `-h` 的帮助信息是自动生成的
--- code
import argparse

parser = argparse.ArgumentParser(prog="clausecheck", description="Review a contract")
parser.add_argument("path", help="contract file (.txt or .pdf)")
parser.add_argument("--out", help="where to write the JSON report")
parser.add_argument("--mode", choices=["mock", "deepseek", "local"], default="mock")
parser.add_argument("--limit", type=int, help="review only the first N clauses")
parser.add_argument("--verbose", action="store_true")

args = parser.parse_args(["data/sample_contract.txt", "--limit", "5", "--verbose"])
print(args)
print(args.path, args.mode, args.limit + 1, args.verbose)

try:
    parser.parse_args(["-h"])
except SystemExit as e:
    print("exit code:", e.code)

@@ concept
title: main(argv)、退出码和 __name__
--- body
项目的写法（`clausecheck/cli.py` 和 `__main__.py`）：

```python
def main(argv=None):
    args = build_parser().parse_args(argv)
    ...
    return 0

if __name__ == "__main__":
    raise SystemExit(main())
```

- `parse_args(argv)`：`argv` 是 `None` 时读真正的命令行；测试里传一个列表 `main(["c.txt", "--limit", "2"])`，不用开终端
- **退出码**：`0` 成功，`1` 出错（比如文件不存在），argparse 参数错误是 `2`。脚本和 CI 靠它判断成败，PowerShell 里用 `$LASTEXITCODE` 查看。`raise SystemExit(main())` 把 `main` 的返回值交给系统当退出码
- `__name__`：直接运行这个文件时是 `"__main__"`，被别的文件 `import` 时是模块名。所以测试里 `from clausecheck.cli import main` 不会顺带把程序跑一遍
- `python -m clausecheck` 运行的就是包里的 `__main__.py`，它只有两行：`from .cli import main` 和 `raise SystemExit(main())`

本页里 `__name__` 也是 `"__main__"`，但没有真的命令行，所以下面直接调用 `main([...])`。如果你在本页写了 `raise SystemExit(main())`，会看到一段「缺少参数」的用法错误：这里没有命令行参数可读，这是正常的。
--- code
import argparse
from pathlib import Path

def build_parser():
    p = argparse.ArgumentParser(prog="clausecheck")
    p.add_argument("path")
    return p

def main(argv=None):
    args = build_parser().parse_args(argv)
    path = Path(args.path)
    if not path.exists():
        print(f"error: {path} not found")
        return 1
    print(f"{path.name}: {len(path.read_text(encoding='utf-8'))} chars")
    return 0

demo = Path("work/d10/demo/c.txt")
demo.parent.mkdir(parents=True, exist_ok=True)
demo.write_text("8.1 Cap on Liability\nLiability is unlimited.\n", encoding="utf-8")
print("exit code:", main(["work/d10/demo/c.txt"]))
print("exit code:", main(["work/d10/demo/missing.txt"]))
try:
    main([])
except SystemExit as e:
    print("exit code:", e.code)
print(__name__)

@@ concept
title: 环境变量和配置
--- body
有些设置不该写死在代码里：API 密钥、运行模式、最多几步。它们放在**环境变量**里：

- 读：`os.getenv("CLAUSECHECK_MODE", "mock")`，没设置就用默认值。**读出来永远是字符串**，数字要自己转：`config.py` 里就写着 `int(os.getenv("CLAUSECHECK_MAX_STEPS", "6"))`
- PowerShell 里临时设置：`$env:CLAUSECHECK_MODE="mock"`
- 密钥写在项目根目录的 `.env` 文件里，`python-dotenv` 的 `load_dotenv()` 把它读进环境变量。`.env` 写在 `.gitignore` 里，所以**密钥永远不进代码、不进 git**
- 优先级：**命令行参数 > 环境变量 > 默认值**。`cli.py` 的 `cmd_review` 先 `Settings()`（读环境变量），命令行给了 `--mode` 再覆盖它
- 写函数时把环境当参数传进来（一个 `env` 字典），测试就不用去改全局的 `os.environ`
--- code
import os

def resolve_steps(cli_value, env):
    if cli_value is not None:
        return cli_value
    return int(env.get("CLAUSECHECK_MAX_STEPS", "6"))

print(resolve_steps(None, {}))
print(resolve_steps(None, {"CLAUSECHECK_MAX_STEPS": "3"}))
print(resolve_steps(10, {"CLAUSECHECK_MAX_STEPS": "3"}))

os.environ["CLAUSECHECK_MODE"] = "deepseek"
print(os.getenv("CLAUSECHECK_MODE", "mock"), type(os.getenv("CLAUSECHECK_MODE")).__name__)
del os.environ["CLAUSECHECK_MODE"]
print(os.getenv("CLAUSECHECK_MODE", "mock"))

--- prompt
写 `count_lines(path)`：返回文件里**非空行**的行数（只有空格的行也算空行）。用 `with open(path, encoding="utf-8") as f:` 打开。

例：文件内容是 `"8.1 Cap\n\n   \nLiability is capped.\n"` 时返回 `2`。测试会自己在 `work/d10/lines/` 里准备文件。
--- starter

    pass
--- solution
def count_lines(path):
    count = 0
    with open(path, encoding="utf-8") as f:
        for line in f:
            if line.strip():
                count += 1
    return count

type: code
title: 读合同，报清楚的错
level: 2
--- prompt
仿照项目的 `split.load_contract` 写 `load_contract(path)`：

- 文件不存在：`raise FileNotFoundError(f"contract not found: {path}")`
- 文件存在，但去掉空白后是空的：`raise ValueError(f"contract is empty: {文件名}")`，文件名用 `.name`（不带文件夹）
- 否则返回文件内容（`encoding="utf-8"`）

Python 自己也会在文件不存在时报 `FileNotFoundError`，但信息是 `[Errno 2] No such file or directory: ...`。**先检查，再报一个人一眼能看懂的错**，是写命令行工具的好习惯。
--- starter
from pathlib import Path

def load_contract(path):
    path = Path(path)
    pass
--- solution
from pathlib import Path

def load_contract(path):
    path = Path(path)
    if not path.exists():
        raise FileNotFoundError(f"contract not found: {path}")
    text = path.read_text(encoding="utf-8")
    if not text.strip():
        raise ValueError(f"contract is empty: {path.name}")
    return text
--- tests

_dir = Path("work/d10/load")
_dir.mkdir(parents=True, exist_ok=True)

(_dir / "blank.txt").write_text("  \n\n", encoding="utf-8")

expect("正常读出内容", lambda: load_contract("work/d10/load/ok.txt"), "8.1 Cap on Liability\nLiability is capped.\n")
expect_raises("文件不存在 → FileNotFoundError", lambda: load_contract("work/d10/load/gone.txt"), FileNotFoundError)
def _msg(name, err):
    try:
        load_contract(f"work/d10/load/{name}")
    except err as e:
        return str(e)

expect_raises("只有空白 → ValueError", lambda: load_contract("work/d10/load/blank.txt"), ValueError)
expect("空文件的信息只写文件名", lambda: _msg("blank.txt", ValueError), "contract is empty: blank.txt")
--- hints
- 先 `if not path.exists():` 就 raise，再读文件。
- 读出来以后，`if not text.strip():` 就是「只有空白」。文件名是 `path.name`。

import json
from pathlib import Path

def load_reports(folder):
    folder = Path(folder)
    if not folder.exists():
        return []
    reports = []
    for path in sorted(folder.glob("*.json")):
        try:
            data = json.loads(path.read_text(encoding="utf-8"))
        except json.JSONDecodeError:
            raise ValueError(f"bad JSON in {path.name}")
        data["file"] = path.name
        reports.append(data)
    return reports

def resolve_mode(cli_value, env):
    if cli_value is not None:
        value = cli_value

--- solution
import json
from pathlib import Path

def merge_reports(folder, out_path):
    folder = Path(folder)
    paths = sorted(folder.glob("*.json")) if folder.exists() else []
    contracts = []
    counts = {}
    for p in paths:
        report = json.loads(p.read_text(encoding="utf-8"))
        contracts.append(report["contract"])
        for verdict, n in report["counts"].items():
            counts[verdict] = counts.get(verdict, 0) + n
    merged = {"files": len(paths), "contracts": contracts, "counts": counts}
    out = Path(out_path)
    out.parent.mkdir(parents=True, exist_ok=True)
    with open(out, "w", encoding="utf-8") as f:
        json.dump(merged, f, indent=2)
    return merged

- 可选参数 `--only`：只能是 `accept` / `flag` / `redline`；不合法时由 argparse 报错退出（`SystemExit`）
- 没给 `--only`：按判定的字母顺序，每种判定打印一行 `判定: 次数`，例如 `accept: 2`
- 给了 `--only flag`：只打印一行 `flag: 次数`（文件里没有这种判定就打印 `flag: 0`）
- 成功返回 `0`；文件不存在时打印 `error: file not found: <path>` 并返回 `1`
--- solution
import argparse
import csv
from collections import Counter
from pathlib import Path

def main(argv=None):
    parser = argparse.ArgumentParser(prog="count-verdicts")
    parser.add_argument("path")
    parser.add_argument("--only", choices=["accept", "flag", "redline"])
    args = parser.parse_args(argv)
    path = Path(args.path)
    if not path.exists():
        print(f"error: file not found: {path}")
        return 1
    with open(path, encoding="utf-8", newline="") as f:
        counts = Counter(row["verdict"] for row in csv.DictReader(f))
    if args.only:
        print(f"{args.only}: {counts[args.only]}")
    else:
        for verdict in sorted(counts):
            print(f"{verdict}: {counts[verdict]}")
    return 0

import json
from pathlib import Path

REQUIRED = ("id", "topic", "severity")

def load_playbook(path):
    data = json.loads(Path(path).read_text(encoding="utf-8"))
    if not isinstance(data, dict) or not isinstance(data.get("rules"), list):
        raise ValueError("playbook needs a 'rules' list")
    by_topic = {}
    for i, rule in enumerate(data["rules"]):
        for key in REQUIRED:
            if key not in rule:
                raise ValueError(f"rule {i} is missing '{key}'")
        by_topic.setdefault(rule["topic"], []).append(rule["id"])
    return by_topic
