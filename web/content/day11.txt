@@ concept
title: 为什么需要检索（RAG）
--- body
模型没见过这个客户的 playbook，也没见过这份合同。资料少时可以全塞进 prompt（DeepSeek 模式下项目就把整份合同放进 system prompt，见 `config.py` 的 `full_contract`）；资料一多，就又贵又慢、会超出上下文长度，无关内容还会让模型看漏。

**RAG**（Retrieval-Augmented Generation，检索增强生成）：**先找出和问题相关的几段，只把它们放进 prompt，再让模型回答。**

Clause Check 用的是最简单的一种：模型先判断条款的主题，再调用工具 `lookup_playbook(topic)`，`playbook.py` 只返回这个主题的几条规则，而不是整本 playbook。

排错时记住第 7 天的话：**检索错了，看起来就像模型推理错了。**先看送进模型的片段对不对。
--- code
PLAYBOOK = [
    {"id": "PB-01", "topic": "liability_cap", "text": "Liability is capped at 100% of the fees paid in the prior 12 months."},
    {"id": "PB-03", "topic": "auto_renewal", "text": "Renewal periods must not exceed 12 months."},
    {"id": "PB-05", "topic": "payment", "text": "Payment within 30 days; no suspension without notice."},
    {"id": "PB-07", "topic": "termination", "text": "Customer may terminate for convenience on 30 days' notice."},
]

def lookup_playbook(topic):
    return [r for r in PLAYBOOK if r["topic"] == topic]

clause = "This Agreement renews automatically for successive twenty-four (24) month periods."
rules = lookup_playbook("auto_renewal")
prompt = "Rules:\n" + "\n".join(f"[{r['id']}] {r['text']}" for r in rules) + "\n\nClause:\n" + clause
print(prompt)
print(f"\nretrieved {len(rules)} of {len(PLAYBOOK)} rules")

@@ concept
title: 文本清洗
--- body
从 PDF 抽出来的文字很脏：多余的空格和换行，还有每页都有的页眉页脚（`CloudNotes Confidential`、`Page 3 of 12`）。不清洗的话，页脚会混进条款正文，还可能被当成「相关内容」检索出来。

- `re.sub(r"\s+", " ", text).strip()`：所有连续空白（空格、换行、制表符）变成一个空格
- 去页眉页脚：逐行看，**整行**匹配 `page \d+ of \d+` 这类模式的扔掉。`re.fullmatch(模式, 文字)` 要求整段文字都匹配，不是只找到一部分就算。项目 `parse.py` 的 `_strip_repeated_lines` 更聪明：在大多数页上都重复出现的行，就当页眉页脚删掉
- **小写只用来比较**：检索时用 `text.lower()`；展示给律师、引用原文时用原文
--- code
import re

page = """CloudNotes Confidential
3.2   Late Payment
Overdue amounts accrue   interest at three percent
(3%) per month.
Page 3 of 12
"""
kept = []
for line in page.splitlines():
    s = line.strip()
    if re.fullmatch(r"page \d+ of \d+", s.lower()) or s == "CloudNotes Confidential":
        continue
    kept.append(line)
clean = re.sub(r"\s+", " ", " ".join(kept)).strip()
print(repr(clean))
print(clean.lower())
# 正文里提到 page 的句子：整行不是「page 数字 of 数字」，所以不匹配（None），不会被删
print(re.fullmatch(r"page \d+ of \d+", "see page 3 of the order form"))

@@ concept
title: 切块：按结构、按长度、带重叠
--- body
检索的单位叫**块（chunk）**。怎么切，决定了能找到什么：

- **按结构切**：合同天然有编号标题，一条条款就是一块。项目 `split.py` 就是这么做的（文件开头写着 structure-aware chunking），每块带着编号、标题和交叉引用
- **按长度切**：没有结构的长文字，每 `size` 个字符一块。相邻两块**重叠** `overlap` 个字符，免得一句话正好被切成两半、两边都不完整。每次前进 `step = size - overlap`
- 每块都要带上 `id` 和出处（比如起始位置 `start`），后面引用、排错都靠它

经典错误：`overlap >= size` 时 `step <= 0`，循环永远不前进。所以要先检查参数，不合理就 `raise ValueError`。
--- code
text = "ABCDEFGHIJ"
size, overlap = 4, 1
step = size - overlap
start = 0
while True:
    print(" " * start + text[start:start + size], "start =", start)
    if start + size >= len(text):
        break
    start += step

@@ concept
title: token 估算和预算
--- body
模型按 **token** 收费，上下文长度也按 token 算。token 是分词器切出来的小片段，不等于字，也不等于词。写代码前先粗估：

- 英文：大约 **4 个字符 ≈ 1 个 token**
- 中文：不同模型的分词器差别很大。OpenAI 较早的分词器一个汉字常常要 1–2 个 token；DeepSeek 文档给的粗略换算是 1 个中文字符约 0.6 token、1 个英文字符约 0.3 token（以官方文档为准）
- 精确数字看接口返回的 `usage`（第 4 天），估算只用来做计划

**预算** = 上下文长度 − 系统提示和问题 − 给回答留的空间。剩下的空间按相关度从高到低，一块一块往里放，放不下的跳过。
--- code
import math

def estimate_tokens(text):
    return math.ceil(len(text) / 4)

chunks = [
    {"id": "c3", "text": "Liability is capped at 100% of the fees paid in the prior 12 months."},
    {"id": "c7", "text": "Either party may terminate for material breach on thirty days' notice."},
    {"id": "c1", "text": "Definitions."},
]
context_window = 120
prompt_tokens = 60
answer_tokens = 30
budget = context_window - prompt_tokens - answer_tokens
print("budget:", budget)
for c in chunks:
    print(c["id"], len(c["text"]), "chars ->", estimate_tokens(c["text"]), "tokens")

@@ concept
title: 关键词检索
--- body
最简单的检索：问题里的词在块里出现得越多，这块越相关。

1. 分词：`re.findall(r"[a-z0-9]+", text.lower())`
2. 去掉**停用词**（the、of、and 这些到处都有的词，留着只会制造噪音）
3. 打分：问题里有几个**不同的**词出现在这块里（集合交集，第 8 天）
4. 按分数从高到低排，取前 k 个；0 分的不要

Python 的 `sorted` 是**稳定**的：分数相同的元素保持原来的先后顺序，所以只按 `-分数` 排就行。项目的规则版审查（`review.py` 的 `rule_based_review`）就是这样选主题的：数一数每个主题的关键词在条款里命中几次。

缺点：只认字面。问 cancel，找不到写着 terminate 的条款，这叫**同义词问题**。生产里常用的 BM25 也是关键词法，只是打分更讲究（越少见的词分越高），同义词问题照样存在。
--- code
import re

STOP = {"the", "a", "an", "of", "to", "and", "or", "in", "on", "for", "is", "are", "be", "shall", "may", "we", "can", "this", "that"}

def tokenize(text):
    return [w for w in re.findall(r"[a-z0-9]+", text.lower()) if w not in STOP]

chunks = [
    {"id": "c1", "text": "Either party may terminate this Agreement for material breach."},
    {"id": "c2", "text": "Fees are payable within thirty (30) days of the invoice date."},
    {"id": "c3", "text": "Late fees accrue interest; Provider may suspend the Service."},
]
for q in ["When are fees payable?", "Can we cancel early?"]:
    words = set(tokenize(q))
    scores = {c["id"]: len(words & set(tokenize(c["text"]))) for c in chunks}
    print(q, tokenize(q), scores)

@@ concept
title: 向量和余弦相似度
--- body
另一种思路：把每段文字变成一个**向量**（一串小数），意思相近的文字，向量的**方向**也相近。比较两个方向用**余弦相似度**：

```python
dot = sum(x * y for x, y in zip(a, b))       # 点积
norm_a = math.sqrt(sum(x * x for x in a))    # 向量的长度
cos = dot / (norm_a * norm_b)
```

- 1：方向完全相同；0：互不相关；-1：方向相反
- 只看方向不看长短：`[1, 2]` 和 `[2, 4]` 的余弦是 1
- 边界：全 0 向量没有方向，长度是 0，直接除会 `ZeroDivisionError`。约定返回 `0.0`
- 分母要加括号：`dot / norm_a * norm_b` 是先除后乘，算错了还不报错
--- code
import math

a = [1.0, 2.0, 0.0]
b = [2.0, 4.0, 0.0]
c = [0.0, 0.0, 3.0]

dot_ab = sum(x * y for x, y in zip(a, b))
norm_a = math.sqrt(sum(x * x for x in a))
norm_b = math.sqrt(sum(x * x for x in b))
print(dot_ab, round(norm_a, 3), round(norm_b, 3))
print("cos(a, b) =", round(dot_ab / (norm_a * norm_b), 3))
print("wrong    =", round(dot_ab / norm_a * norm_b, 3))

dot_ac = sum(x * y for x, y in zip(a, c))
print("cos(a, c) =", dot_ac / (norm_a * math.sqrt(sum(x * x for x in c))))

title: embeddings 接口
mock: yes
--- body
**embedding 模型**把一段文字变成固定长度的向量，意思相近的文字方向也相近。所以问 cancel 也能找到写着 terminate 的条款。

- 请求：`POST https://api.openai.com/v1/embeddings`，请求头 `Authorization: Bearer <OPENAI_API_KEY>`，请求体 `{"model": "text-embedding-3-small", "input": [文字1, 文字2, ...]}`
- 回答：`data` 列表，每项有 `index` 和 `embedding`，第 i 项对应第 i 段文字
- **DeepSeek 没有 embeddings 接口。**常用的是 OpenAI 的 `text-embedding-3-small`（1536 维），或者 LM Studio 里加载的本地 embedding 模型（`http://127.0.0.1:1234/v1/embeddings`，格式一样）
- 本页的模拟接口格式和 OpenAI 一样，但不是真模型：它把单词（去掉停用词、合并几组合同同义词）哈希成 256 维向量，别把它的分数当真
- 文档的向量**算一次、存起来**，每次提问只算问题的；一批文字**一次请求**发完
--- code
import math
import os
import requests

EMBED_URL = "https://api.openai.com/v1/embeddings"
headers = {"Authorization": f"Bearer {os.getenv('OPENAI_API_KEY')}"}
texts = [
    "Can we cancel the contract early?",
    "Either party may terminate this Agreement for material breach.",
    "Fees are payable within thirty (30) days of the invoice date.",
]
data = requests.post(EMBED_URL, headers=headers, json={"model": "text-embedding-3-small", "input": texts}).json()
vectors = [d["embedding"] for d in sorted(data["data"], key=lambda d: d["index"])]
print(len(vectors), "vectors,", len(vectors[0]), "numbers each")
print("usage:", data["usage"])

def cosine(a, b):
    na = math.sqrt(sum(x * x for x in a))
    nb = math.sqrt(sum(y * y for y in b))
    if na == 0 or nb == 0:
        return 0.0
    return sum(x * y for x, y in zip(a, b)) / (na * nb)

print("question vs termination:", round(cosine(vectors[0], vectors[1]), 3))
print("question vs payment:    ", round(cosine(vectors[0], vectors[2]), 3))

@@ concept
title: 把检索结果放进 prompt
--- body
检索到的块要**带着编号**放进 prompt，并且告诉模型怎么用它们：

- **只根据片段回答**：不许模型拿「一般合同都这样」来补
- **引用编号**：回答里出现 `[c7]`，你就能用代码检查它引用的片段是不是真的给过它、原文是不是真这么说（第 19 天会写这个检查）
- **允许说不知道**：比编一个答案安全得多
- 顺序：规则在前，片段在中间，问题在最后

下面用了三引号的 f-string：三引号里可以直接换行，`{...}` 照样会被替换。
--- code
import re

chunks = [
    {"id": "c3", "text": "Either party may terminate this Agreement for material breach."},
    {"id": "c7", "text": "Customer may terminate for convenience on 30 days' notice."},
]
question = "Can we cancel early?"
excerpts = "\n".join(f"[{c['id']}] {c['text']}" for c in chunks)
prompt = f"""Answer using ONLY the excerpts below.
After each claim, cite the excerpt id in brackets, e.g. [c2].
If the excerpts do not contain the answer, say: not found in the excerpts.

{excerpts}

Question: {question}"""
print(prompt)

answer = "Yes: the Customer may terminate for convenience on 30 days' notice [c7]."
print("\ncited:", re.findall(r"\[(c\d+)\]", answer))

from pathlib import Path

def load_docs(folder):
    folder = Path(folder)
    if not folder.exists():
        return []
    return [{"id": p.stem, "text": p.read_text(encoding="utf-8")} for p in sorted(folder.glob("*.txt"))]

--- solution
import re

FOOTER = re.compile(r"page \d+ of \d+")

def clean(text):
    kept = [line for line in text.splitlines() if not FOOTER.fullmatch(line.strip().lower())]
    return re.sub(r"\s+", " ", " ".join(kept)).strip()
--- tests

type: code
title: 按长度切块，带重叠
level: 2
--- prompt
写 `chunk_fixed(text, size, overlap)`：

- 第一块从位置 0 开始，每次前进 `step = size - overlap`
- 每块是 `{"id": "c1", "start": 起始位置, "text": text[start:start + size]}`，编号从 `c1` 开始
- 某一块已经到了文字末尾（`start + size >= len(text)`）就停，不再切下一块
- `text` 为空返回 `[]`
- 参数不合理时 `raise ValueError`：`size <= 0`、`overlap < 0`、`overlap >= size`

例：`chunk_fixed("abcdefghij", 4, 1)` 切出三块，文字是 `"abcd"`、`"defg"`、`"ghij"`。
--- starter
def chunk_fixed(text, size, overlap):
    chunks = []
    return chunks
--- solution
def chunk_fixed(text, size, overlap):
    if size <= 0 or overlap < 0 or overlap >= size:
        raise ValueError(f"bad size/overlap: {size}/{overlap}")
    chunks = []
    if not text:
        return chunks
    step = size - overlap
    start = 0
    while True:
        chunks.append({"id": f"c{len(chunks) + 1}", "start": start, "text": text[start:start + size]})
        if start + size >= len(text):
            break
        start += step
    return chunks
--- tests
texts = lambda chunks: [c["text"] for c in chunks]
expect("重叠 1 个字符", lambda: texts(chunk_fixed("abcdefghij", 4, 1)), ["abcd", "defg", "ghij"])
expect("第二块的完整样子", lambda: chunk_fixed("abcdefghij", 4, 1)[1], {"id": "c2", "start": 3, "text": "defg"})
expect("不重叠，最后一块短一些", lambda: texts(chunk_fixed("abcdefghij", 4, 0)), ["abcd", "efgh", "ij"])
expect("文字比 size 短", lambda: chunk_fixed("abc", 10, 2), [{"id": "c1", "start": 0, "text": "abc"}])
expect("空文字", lambda: chunk_fixed("", 4, 1), [])
expect_raises("overlap >= size", lambda: chunk_fixed("abcdef", 4, 4), ValueError)
expect_raises("size 为 0", lambda: chunk_fixed("abcdef", 0, 0), ValueError)
--- hints
- 参数检查放在最前面：`if size <= 0 or overlap < 0 or overlap >= size: raise ValueError(...)`。
- 用 `while True:`：先切一块加进列表，再判断 `start + size >= len(text)` 就 `break`，否则 `start += size - overlap`。
- 编号在加进列表之前算：`f"c{len(chunks) + 1}"`。

import re

STOP = {"the", "a", "an", "of", "to", "and", "or", "in", "on", "for", "is", "are", "be", "shall", "may", "we", "can", "this", "that"}

def tokenize(text):
    return [w for w in re.findall(r"[a-z0-9]+", text.lower()) if w not in STOP]

def keyword_score(query, text):
    return len(set(tokenize(query)) & set(tokenize(text)))

def top_k(query, chunks, k):
    scored = []
    for c in chunks:
        score = keyword_score(query, c["text"])
        if score > 0:
            scored.append((score, c["id"]))
    scored = sorted(scored, key=lambda pair: -pair[0])
    return [cid for score, cid in scored[:k]]

def dot(a, b):
    if len(a) != len(b):
        raise ValueError(f"vector lengths differ: {len(a)} vs {len(b)}")
    return sum(x * y for x, y in zip(a, b))

    nb = norm(b)
    if na == 0 or nb == 0:

    return dot(a, b) / (na * nb)

import json
import math
import os
from pathlib import Path
import requests

EMBED_URL = "https://api.openai.com/v1/embeddings"
HEADERS = {"Authorization": f"Bearer {os.getenv('OPENAI_API_KEY')}"}

def embed_texts(texts):
    if not texts:
        return []
    resp = requests.post(EMBED_URL, headers=HEADERS, json={"model": "text-embedding-3-small", "input": texts})
    resp.raise_for_status()
    return [d["embedding"] for d in sorted(resp.json()["data"], key=lambda d: d["index"])]

def cosine(a, b):
    na = math.sqrt(sum(x * x for x in a))
    nb = math.sqrt(sum(y * y for y in b))
    if na == 0 or nb == 0:
        return 0.0
    return sum(x * y for x, y in zip(a, b)) / (na * nb)

def build_index(chunks, path):
    vectors = embed_texts([c["text"] for c in chunks])
    rows = [{"id": c["id"], "text": c["text"], "vector": v} for c, v in zip(chunks, vectors)]
    path = Path(path)
    path.parent.mkdir(parents=True, exist_ok=True)
    path.write_text(json.dumps(rows), encoding="utf-8")
    return len(rows)

def search(path, query, k):
    rows = json.loads(Path(path).read_text(encoding="utf-8"))
    q = embed_texts([query])[0]
    ranked = sorted(rows, key=lambda r: -cosine(q, r["vector"]))
    return [r["id"] for r in ranked[:k]]

--- solution
import re

HEAD = re.compile(r"\d+(\.\d+)*\s+[A-Z]")

def chunk_by_heading(text):
    blocks = []
    for line in text.splitlines():
        s = line.strip()
        if HEAD.match(s):
            blocks.append({"heading": s, "lines": []})
        elif blocks:
            blocks[-1]["lines"].append(s)
    chunks = []
    for b in blocks:
        body = re.sub(r"\s+", " ", " ".join(b["lines"])).strip()
        if body:
            chunks.append({"id": f"c{len(chunks) + 1}", "heading": b["heading"], "text": body})
    return chunks

import re

STOP = {"the", "a", "an", "of", "to", "and", "is", "are", "we", "can", "do"}

def tokenize(text):
    return {w for w in re.findall(r"[a-z0-9]+", text.lower()) if w not in STOP}

def retrieve(query, chunks, k):
    q = tokenize(query)
    scored = []
    for c in chunks:
        score = len(q & tokenize(c["text"]))
        if score > 0:
            scored.append((score, c["id"]))
    scored = sorted(scored, key=lambda pair: -pair[0])
    return [cid for score, cid in scored[:k]]

写 `answer_context(query, chunks, k, budget)`，返回要发给模型的 prompt 字符串（每块是 `{"id": ..., "text": ...}`）：

1. **检索**：查询词 = 查询里**长度至少 4** 的单词（转小写，用 `re.findall(r"[a-z0-9]+", ...)` 取词，去重）。一块的分数 = 有多少个查询词出现在这块 `text` 的单词里（同样转小写取词）。0 分的不要；分数从高到低、同分保持原顺序，取前 `k` 块
2. **装预算**：按上一步的顺序，每块估算 `math.ceil(len(text) / 4)` 个 token；加上这块会超过 `budget` 就跳过它，继续看下一块
3. **拼 prompt**：第一行 `Answer using only these excerpts and cite their ids.`，然后每块一行 `[id] text`，最后一行 `Question: <query>`，用 `"\n"` 连接
4. 一块都没选上时，返回 `"No relevant excerpts found."`
--- solution
import math
import re

def _words(text):
    return set(re.findall(r"[a-z0-9]+", text.lower()))

def answer_context(query, chunks, k, budget):
    q = {w for w in _words(query) if len(w) >= 4}
    scored = []
    for c in chunks:
        score = len(q & _words(c["text"]))
        if score > 0:
            scored.append((score, c))
    ranked = [c for score, c in sorted(scored, key=lambda p: -p[0])][:k]
    picked = []
    used = 0
    for c in ranked:
        cost = math.ceil(len(c["text"]) / 4)
        if used + cost > budget:
            continue
        picked.append(c)
        used += cost
    if not picked:
        return "No relevant excerpts found."
    lines = ["Answer using only these excerpts and cite their ids."]
    lines += [f"[{c['id']}] {c['text']}" for c in picked]
    lines.append(f"Question: {query}")
    return "\n".join(lines)
