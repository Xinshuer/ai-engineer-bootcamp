@@ concept
title: JSON：文字和字典之间的桥
--- body
模型返回的是**文字**，程序要用的是**字典**。JSON 是两者之间的格式。

- `json.loads(文字)` → 字典/列表（s 代表 string）
- `json.dumps(对象)` → 文字；加 `ensure_ascii=False` 中文不转义，`indent=2` 缩进好看

对照记：JSON 的 `true` / `false` / `null` 对应 Python 的 `True` / `False` / `None`；JSON 字符串**只能用双引号**。
--- code
import json

raw = '{"clause_id": "8.1", "verdict": "flag", "ok": true, "note": null}'
data = json.loads(raw)
print(type(data), data["verdict"], data["ok"], data["note"])

back = json.dumps({"verdict": "accept", "high": False}, indent=2)
print(back)

@@ concept
title: try / except：预料到的错误要接住
--- body
有些错误不是 bug，而是**外部输入不可靠**：模型返回的 JSON 格式坏了、字典里缺字段。这时用 try/except 接住它，给出合理的结果，而不是让整个程序崩掉。

```python
try:
    data = json.loads(raw)
except json.JSONDecodeError:
    data = None
```

- 只写你**预料到**的错误类型，不要写光秃秃的 `except:`，它会把真正的 bug 也藏起来
- `except SomeError as e:` 可以拿到错误对象，`str(e)` 是错误信息
--- code
import json

for raw in ['{"verdict": "flag"}', "Sure! {bad json"]:
    try:
        data = json.loads(raw)
        print("ok:", data["verdict"])
    except json.JSONDecodeError as e:
        print("bad json:", e)

@@ concept
title: 正则入门：在文字里找模式
--- body
正则表达式描述「长什么样的文字」。最常用的几个符号：

- `\d` 一个数字，`\d+` 一个或多个数字
- `\.` 字面上的点（单独的 `.` 表示「任意字符」）
- `( )` 分组：只把括号里的部分拿出来
- `?` 前面的东西可有可无

`re.findall(模式, 文字)` 返回所有匹配；`re.search` 返回第一个匹配（找不到是 `None`），用 `.group(1)` 取第一个括号里的内容。模式字符串前加 `r`，让反斜杠保持原样。
--- code
import re

text = "Subject to Section 12, see also Section 4.2. Pay within 30 days."
print(re.findall(r"\d+", text))
print(re.findall(r"Section (\d+(?:\.\d+)?)", text))
m = re.search(r"(\d+) days", text)
print(m.group(1) if m else None)

@@ concept
title: 类：把数据和操作放在一起
--- body
类是自己定义的「类型」。一个条款有编号、标题、正文，还有一些相关的操作，可以写成：

```python
class Clause:
    def __init__(self, clause_id, heading, text):
        self.clause_id = clause_id
        self.heading = heading
        self.text = text

    def is_title(self):
        return self.text.strip() == ""
```

- `__init__` 在创建对象时自动运行，负责存数据；`self` 指「这个对象自己」
- `Clause("8.1", "Cap", "...")` 创建一个对象；`c.heading` 读属性；`c.is_title()` 调方法
- 方法的第一个参数永远是 `self`
--- code
class Clause:
    def __init__(self, clause_id, heading, text):
        self.clause_id = clause_id
        self.heading = heading
        self.text = text

    def is_title(self):
        return self.text.strip() == ""

    def label(self):
        return f"{self.clause_id} {self.heading}"

c = Clause("8.1", "Cap on Liability", "Each party's liability ...")
t = Clause("8", "Limitation of Liability", "")
print(c.label(), c.is_title())
print(t.label(), t.is_title())

title: 类型标注：写给人和工具看的说明
--- body
```python
def risk_score(risk: str) -> int:
```

意思是「参数 risk 应该是字符串，返回整数」。常见写法：`list[str]`、`dict[str, int]`、`str | None`（可能是 None）。

**Python 运行时不检查这些标注**，传错类型也照样运行。它的价值在于：读代码的人一眼知道该传什么；编辑器能提示；**Pydantic 会读这些标注来校验数据**（明天的内容）。TypeScript 则会在运行前真正检查（第 5 天）。
--- code
def risk_score(risk: str) -> int:
    scores: dict[str, int] = {"low": 1, "medium": 2, "high": 3}
    return scores.get(risk, 0)

def first_id(ids: list[str]) -> str | None:
    return ids[0] if ids else None

print(risk_score("high"), risk_score("urgent"))
print(first_id(["3.1", "8.1"]), first_id([]))

--- solution
class VerdictTally:
    def __init__(self):
        self.counts = {}

    def add(self, verdict):
        self.counts[verdict] = self.counts.get(verdict, 0) + 1

    def count(self, verdict):
        return self.counts.get(verdict, 0)

    def most_common(self):
        best = None
        for v, n in self.counts.items():
            if best is None or n > self.counts[best]:
                best = v
        return best
--- tests
def _make(*vs):
    t = VerdictTally()
    for v in vs:
        t.add(v)
    return t
expect("count", lambda: _make("flag", "accept", "flag").count("flag"), 2)
expect("没记过是 0", lambda: _make("flag").count("redline"), 0)
expect("最多的", lambda: _make("accept", "flag", "flag").most_common(), "flag")
expect("并列取先出现的", lambda: _make("redline", "accept").most_common(), "redline")
expect("空的返回 None", lambda: VerdictTally().most_common(), None)
--- hints
- `add` 和 `count` 就是计数写法，只是字典变成了 `self.counts`。
- `most_common`：遍历 `self.counts.items()`，记住目前最大的那个；只有「严格大于」才替换，这样并列时保留先出现的。

ALLOWED = ("accept", "flag", "redline")

def parse_result(raw):

写类 `Rule`：创建时接收 `rule_id`、`topic`、`severity` 并保存为同名属性；方法 `is_high()` 在 `severity` 为 `"high"` 时返回 `True`；方法 `summary()` 返回 `"PB-01 (payment, high)"` 这样的字符串。
--- solution
class Rule:
    def __init__(self, rule_id, topic, severity):
        self.rule_id = rule_id
        self.topic = topic
        self.severity = severity

    def is_high(self):
        return self.severity == "high"

    def summary(self):
        return f"{self.rule_id} ({self.topic}, {self.severity})"
--- tests
