@@ concept
title: for 循环
--- body
`for 变量 in 列表:` 把列表里的元素一个一个拿出来，每次执行一遍下面缩进的代码。

`range(n)` 生成 0 到 n-1 的数字，`range(1, 4)` 是 1、2、3（不含结尾）。

循环变量的名字随便起，但要有意义：遍历条款就叫 `clause` 或 `c`，不要叫 `x`。
--- code
ids = ["3.1", "4.2", "8.1"]
for cid in ids:
    print("reviewing", cid)

for i in range(3):
    print("attempt", i + 1)

@@ concept
title: 累加：在循环外准备，在循环里更新
--- body
几乎所有「统计」都是同一个形状：

1. 循环**之前**准备一个初始值（`0`、空列表 `[]`、空字典 `{}`）
2. 循环**里面**更新它
3. 循环**之后** return 它

最常见的 bug：把初始值写进了循环里，每一轮都被清零。
--- code
lengths = [120, 45, 300]
total = 0
for n in lengths:
    total = total + n
print("total", total)

long_ones = []
for n in lengths:
    if n > 100:
        long_ones.append(n)
print(long_ones)

@@ concept
title: 字典：用名字找值
--- body
字典 `{键: 值, ...}` 按「键」找「值」，就像查表。

- `d["8.1"]` 取值，键不存在会报 `KeyError`
- `d.get("4.2")` 键不存在时返回 `None`；`d.get("4.2", "unknown")` 返回你给的默认值
- `d["4.2"] = "low"` 新增或修改
- `"3.1" in d` 判断键在不在
- `for k, v in d.items():` 同时遍历键和值

模型返回的 JSON、playbook 规则、统计结果，在 Python 里都是字典。
--- code
risk = {"8.1": "high", "3.1": "low"}
print(risk["8.1"])
print(risk.get("4.2"), risk.get("4.2", "unknown"))
risk["4.2"] = "medium"
for cid, level in risk.items():
    print(cid, "->", level)

@@ concept
title: 计数的标准写法
--- body
统计每种判定出现几次，是这个项目里最常见的操作。标准写法：

```python
counts = {}
for v in verdicts:
    counts[v] = counts.get(v, 0) + 1
```

`counts.get(v, 0)` 的意思是「之前数到几了，没数过就当 0」。直接写 `counts[v] += 1` 会在第一次遇到某个值时报 `KeyError`。
--- code
verdicts = ["accept", "flag", "accept", "redline", "accept"]
counts = {}
for v in verdicts:
    counts[v] = counts.get(v, 0) + 1
print(counts)

@@ concept
title: 函数：默认参数和提前 return
--- body
- **默认参数**：`def label(cid, prefix="Clause"):`，调用时不传 `prefix` 就用默认值
- **提前 return**：找到答案就立刻 `return`，函数马上结束；循环走完都没找到，再在最后 `return None`

「找一个东西」的标准形状：

```python
def find(items, target):
    for x in items:
        if x == target:
            return x
    return None
```

注意最后那行 `return None` 和 `for` 对齐，不在循环里面。
--- code
def label(cid, prefix="Clause"):
    return f"{prefix} {cid}"

def first_high(clauses):
    for c in clauses:
        if c["risk"] == "high":
            return c["id"]
    return None

print(label("8.1"), label("8.1", "Section"))
print(first_high([{"id": "3.1", "risk": "low"}, {"id": "8.1", "risk": "high"}]))
print(first_high([]))

@@ concept
title: 列表推导式：一行写完筛选和变换
--- body
`[表达式 for 变量 in 列表 if 条件]` 等价于「准备空列表 → 循环 → 满足条件就 append」。

```python
ids = [c["id"] for c in clauses if c["risk"] == "high"]
```

先把普通 for 循环写熟，再用推导式。两种写法测试都认，看得懂就行，面试时写哪种都可以。
--- code
clauses = [
    {"id": "3.1", "risk": "low"},
    {"id": "8.1", "risk": "high"},
    {"id": "10.1", "risk": "high"},
]
print([c["id"] for c in clauses])
print([c["id"] for c in clauses if c["risk"] == "high"])
print([len(c["id"]) for c in clauses])

@@ concept
title: 排序和 while
--- body
**排序**：`sorted(列表)` 返回排好序的新列表。按字段排序用 `key=`：

```python
RISK_ORDER = {"high": 0, "medium": 1, "low": 2}
sorted(clauses, key=lambda c: RISK_ORDER[c["risk"]])
```

`lambda c: ...` 是一个没有名字的小函数：给它一条条款，它返回用来比较的值。`sorted` 是稳定的：比较值相同的元素保持原来的顺序。

**while**：条件成立就一直循环，适合「不知道要循环几次」的情况，比如接口失败时重试。一定要确保循环里有东西在变，否则就是死循环。
--- code
RISK_ORDER = {"high": 0, "medium": 1, "low": 2}
clauses = [{"id": "3.1", "risk": "low"}, {"id": "8.1", "risk": "high"}, {"id": "4.2", "risk": "medium"}]
for c in sorted(clauses, key=lambda c: RISK_ORDER[c["risk"]]):
    print(c["id"], c["risk"])

attempt = 1
while attempt <= 3:
    print("try", attempt)
    attempt = attempt + 1

    total = 0

@@ item d2-10
type: choice
title: print 和 return
level: 1
cards: d1:函数：def 和 return; d1:代码怎么跑：print 和注释
--- context
前面「修 bug：只打印不返回」那道题，问题就出在这两个词上。新手写统计函数时，这是最常见的误会之一。
--- prompt
关于 `print` 和 `return`，哪个说法是对的？
--- options
- 两者一样，都能把结果交给调用者
- `return` 把值交给调用者并结束函数；`print` 只是显示在屏幕上
- 函数里只能用其中一个
- `print` 之后函数就结束了
answer: 2
--- explain
`return` 是函数的「输出口」：调用 `x = f()` 时，`x` 拿到的是 return 的值；执行到 return 函数立即结束。`print` 只影响屏幕，不影响程序拿到的值。一个没有 return 的函数，调用结果是 `None`。

        pass

--- solution
def first_success(statuses):
    i = 0
    while i < len(statuses):
        if statuses[i] == 200:
            return i + 1
        i = i + 1
    return -1

- 找到 200 就 `return i + 1`（下标从 0 开始，次数从 1 开始）；否则 `i = i + 1`。
