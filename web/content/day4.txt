@@ concept
title: Pydantic：给数据定规矩
--- body
昨天手写的 `validate_verdict` 很繁琐。Pydantic 让你**用类型标注描述数据**，它负责检查：

```python
from typing import Literal
from pydantic import BaseModel

class Verdict(BaseModel):
    clause_id: str
    verdict: Literal["accept", "flag", "redline"]
    confidence: float = 0.5
```

- `Literal[...]` 表示「只能是这几个值之一」
- 有默认值的字段可以不传
- 创建对象时自动校验；能安全转换的会转换（字符串 `"0.9"` → `0.9`），不合法就报 `ValidationError`
- `v.model_dump()` 转回字典
--- code
from typing import Literal
from pydantic import BaseModel

class Verdict(BaseModel):
    clause_id: str
    verdict: Literal["accept", "flag", "redline"]
    confidence: float = 0.5

v = Verdict(clause_id="8.1", verdict="flag")
print(v.verdict, v.confidence)
print(v.model_dump())
w = Verdict(clause_id="12", verdict="accept", confidence="0.9")
print(w.confidence, type(w.confidence))

@@ concept
title: 校验失败：ValidationError
--- body
模型输出的 JSON 文字，可以一步完成「解析 + 校验」：

```python
v = Verdict.model_validate_json(raw)
```

JSON 格式坏了、字段缺了、值不合法，都会抛 `ValidationError`。`e.errors()` 是问题列表，每项有 `loc`（哪个字段）和 `msg`（原因）。

在 Clause Check 里，校验失败时不是让程序崩掉，而是把错误信息**回传给模型**让它改正，这叫「校验回送」。
--- code
from typing import Literal
from pydantic import BaseModel, ValidationError

class Verdict(BaseModel):
    clause_id: str
    verdict: Literal["accept", "flag", "redline"]

for raw in ['{"clause_id": "8.1", "verdict": "flag"}', '{"clause_id": "8.1", "verdict": "HIGH"}', "not json"]:
    try:
        print("ok:", Verdict.model_validate_json(raw))
    except ValidationError as e:
        err = e.errors()[0]
        print("invalid:", err["loc"], err["msg"])

title: Chat API 的请求和回答长什么样
--- body
几乎所有大模型接口（DeepSeek、OpenAI、LM Studio）都用同一种格式。

**请求**：POST 到 `.../chat/completions`，请求头带 `Authorization: Bearer <密钥>`，请求体：

```python
{
    "model": "deepseek-chat",
    "messages": [
        {"role": "system", "content": "你是合同审查助手……"},
        {"role": "user", "content": "请审查这一条：……"},
    ],
    "temperature": 0.3,
}
```

**回答**里最常用的三处：

- `data["choices"][0]["message"]["content"]` 模型说的话
- `data["choices"][0]["finish_reason"]` 为什么停：`"stop"` 说完了，`"tool_calls"` 想调工具
- `data["usage"]["total_tokens"]` 用了多少 token（算钱）
--- code
import json

messages = [
    {"role": "system", "content": "You review contract clauses."},
    {"role": "user", "content": "Review clause 8.1: liability is unlimited."},
]
body = {"model": "deepseek-chat", "messages": messages, "temperature": 0.3}
print(json.dumps(body, indent=2))

@@ concept
title: 状态码和重试
mock: yes
--- body
- `200` 成功
- `400` 请求写错了（字段缺了、模型名不对）：**不要重试**，改代码
- `401` 密钥不对或没带 `Bearer`：**不要重试**
- `429` 请求太频繁、`500` / `503` 服务器问题：**可以重试**，等一下再来

重试要有**上限**（比如 3 次），否则服务一直挂着，你就一直在循环里。生产里还会在每次重试之间等待越来越久（指数退避）。

本页的 `MOCK.fail_next(429, 2)` 会让模拟服务器接下来两次返回 429，用来练习重试。
--- code
import os
import requests

URL = "https://api.deepseek.com/v1/chat/completions"
HEADERS = {"Authorization": f"Bearer {os.getenv('DEEPSEEK_API_KEY')}"}
body = {"model": "deepseek-chat", "messages": [{"role": "user", "content": "hi"}]}

MOCK.fail_next(429, 2)
for attempt in range(1, 4):
    resp = requests.post(URL, headers=HEADERS, json=body)
    print("attempt", attempt, "status", resp.status_code)
    if resp.status_code == 200:
        break

print(requests.post(URL, headers={"Authorization": "wrong"}, json=body).json())

@@ concept
title: 工具调用：模型说「帮我查一下」
mock: yes
--- body
把工具的说明（名字、描述、参数）放进请求的 `tools` 里，模型觉得需要时就不直接回答，而是返回：

```python
finish_reason == "tool_calls"
message["tool_calls"] = [{"id": "call_1", "function": {"name": "lookup_playbook", "arguments": '{"topic": "liability_cap"}'}}]
```

你的代码要：

1. 找到叫这个名字的 Python 函数
2. `json.loads(arguments)` 得到参数，调用它
3. 把模型那条消息和一条 `{"role": "tool", "tool_call_id": ..., "content": 结果}` 加进 messages，**再请求一次**

模型看到工具结果后给出最终回答。这个「请求 → 调工具 → 再请求」的循环就是 Agent。
--- code
import json
import os
import requests

URL = "https://api.deepseek.com/v1/chat/completions"
HEADERS = {"Authorization": f"Bearer {os.getenv('DEEPSEEK_API_KEY')}"}
TOOLS = [{"type": "function", "function": {"name": "lookup_playbook", "description": "Return the customer's rule for a topic", "parameters": {"type": "object", "properties": {"topic": {"type": "string"}}, "required": ["topic"]}}}]

messages = [{"role": "user", "content": "Is unlimited liability acceptable?"}]
data = requests.post(URL, headers=HEADERS, json={"model": "deepseek-chat", "messages": messages, "tools": TOOLS}).json()
choice = data["choices"][0]
print("finish_reason:", choice["finish_reason"])
call = choice["message"]["tool_calls"][0]
print("tool:", call["function"]["name"], json.loads(call["function"]["arguments"]))

@@ concept
title: 随机性：跑一次不算数
mock: yes
--- body
同一个输入，模型两次的回答可能不同。所以评估一个用到模型的函数时，要**跑 N 次看通过率**，而不是跑一次看对错。

本页的模拟服务器会对「AS IS 免责声明」这类条款故意摇摆（约 60% 判 accept），就像真实模型一样。下面的例子数一数 10 次里有几次判 accept。

这就是 Clause Check `evals/run_evals.py` 的核心思想。
--- code
import json
import os
import requests

URL = "https://api.deepseek.com/v1/chat/completions"
HEADERS = {"Authorization": f"Bearer {os.getenv('DEEPSEEK_API_KEY')}"}
clause = 'Review clause 7.2: THE SERVICE IS PROVIDED "AS IS".'
results = []
for _ in range(10):
    body = {"model": "deepseek-chat", "messages": [{"role": "user", "content": clause}], "response_format": {"type": "json_object"}}
    content = requests.post(URL, headers=HEADERS, json=body).json()["choices"][0]["message"]["content"]
    results.append(json.loads(content)["verdict"])
print(results)
print("accept rate:", results.count("accept") / len(results))

from typing import Literal
from pydantic import BaseModel, ValidationError

class Verdict(BaseModel):
    clause_id: str
    verdict: Literal["accept", "flag", "redline"]

def parse_verdict(raw):
    try:
        return Verdict.model_validate_json(raw)
    except ValidationError as e:
        return "INVALID: " + e.errors()[0]["msg"]

import os
import requests

API_URL = "https://api.deepseek.com/v1/chat/completions"
HEADERS = {"Authorization": f"Bearer {os.getenv('DEEPSEEK_API_KEY')}"}

def call_api(body):
    resp = requests.post(API_URL, headers=HEADERS, json=body)
    if resp.status_code != 200:
        raise RuntimeError(f"API error {resp.status_code}: {resp.json()['error']['message']}")
    return resp.json()
--- tests

def _message():
    MOCK.fail_next(500)
    try:
        call_api(GOOD)
    except RuntimeError as e:
        return str(e)
expect("错误信息格式", _message, "API error 500: Internal server error")
--- hints

- f-string 里要用单引号取字典：`resp.json()['error']['message']`（外面已经是双引号了）。

import os
import requests

API_URL = "https://api.deepseek.com/v1/chat/completions"
HEADERS = {"Authorization": f"Bearer {os.getenv('DEEPSEEK_API_KEY')}"}
RETRYABLE = (429, 500, 503)

def ask_with_retry(prompt, max_attempts=3):
    body = {"model": "deepseek-chat", "messages": [{"role": "user", "content": prompt}]}
    for attempt in range(max_attempts):
        resp = requests.post(API_URL, headers=HEADERS, json=body)
        if resp.status_code == 200:
            return resp.json()["choices"][0]["message"]["content"]
        if resp.status_code not in RETRYABLE:
            raise RuntimeError(f"not retryable: {resp.status_code}")
    raise RuntimeError(f"gave up after {max_attempts} attempts")
--- tests

import json

def extract_json(text):
    start = text.find("{")
    end = text.rfind("}")
    if start == -1 or end == -1:
        return None
    return json.loads(text[start:end + 1])
--- tests

expect("干净的 JSON", lambda: extract_json('{"x": 1}'), {"x": 1})
expect("没有大括号", lambda: extract_json("no json here"), None)
--- hints
- `text.find("{")` 找第一个，`text.rfind("}")` 从右边找最后一个，找不到返回 -1。
- 切片要包括最后那个 `}`：`text[start:end + 1]`。

import json

def run_tool_call(call, tools):
    name = call["function"]["name"]
    if name not in tools:
        return f"UNKNOWN_TOOL: {name}"
    args = json.loads(call["function"]["arguments"])
    return tools[name](**args)

import os
from typing import Literal
import requests
from pydantic import BaseModel

API_URL = "https://api.deepseek.com/v1/chat/completions"
HEADERS = {"Authorization": f"Bearer {os.getenv('DEEPSEEK_API_KEY')}"}

class Verdict(BaseModel):
    clause_id: str
    verdict: Literal["accept", "flag", "redline"]
    risk_level: Literal["low", "medium", "high"]
    rationale: str

def classify(clause_text):

    return Verdict.model_validate_json(data["choices"][0]["message"]["content"])

def pass_rate(clause_text, expected, n):
    hits = 0
    for _ in range(n):
        if classify(clause_text).verdict == expected:
            hits += 1
    return hits / n

import json
import os
import requests

API_URL = "https://api.deepseek.com/v1/chat/completions"
HEADERS = {"Authorization": f"Bearer {os.getenv('DEEPSEEK_API_KEY')}"}
TOOLS = [{"type": "function", "function": {"name": "lookup_playbook", "description": "Return the customer's rule for a topic", "parameters": {"type": "object", "properties": {"topic": {"type": "string"}}, "required": ["topic"]}}}]

def lookup_playbook(topic):
    return f"rule for {topic}: cap at 100% of annual fees"

def run_tool_call(call, tools):
    return tools[call["function"]["name"]](**json.loads(call["function"]["arguments"]))

def mini_agent(question, max_steps=3):
    messages = [{"role": "user", "content": question}]
    for _ in range(max_steps):
        body = {"model": "deepseek-chat", "messages": messages, "tools": TOOLS}
        choice = requests.post(API_URL, headers=HEADERS, json=body).json()["choices"][0]
        message = choice["message"]
        if choice["finish_reason"] != "tool_calls":
            return message["content"]
        call = message["tool_calls"][0]
        result = run_tool_call(call, {"lookup_playbook": lookup_playbook})
        messages.append(message)
        messages.append({"role": "tool", "tool_call_id": call["id"], "content": result})
    return "STOPPED"
--- tests
def _run():
    MOCK.reset()
    return [mini_agent("Is unlimited liability acceptable?"), len(MOCK.calls)]
expect("调了工具，拿到最终回答，一共请求 2 次", _run, ["Based on the playbook: rule for liability_cap: cap at 100% of annual fees", 2])
expect("第二次请求里带着工具结果", lambda: MOCK.calls[-1]["body"]["messages"][-1]["role"], "tool")
expect("步数用完返回 STOPPED", lambda: mini_agent("Is unlimited liability acceptable?", max_steps=1), "STOPPED")
--- hints
- 结构：`for _ in range(max_steps):` 里发请求；不是 tool_calls 就 return；是就执行工具、往 messages 里加两条，然后继续下一轮。
- 循环结束还没 return，就 `return "STOPPED"`。

import os
import requests

def total_tokens(prompts):
    headers = {"Authorization": f"Bearer {os.getenv('DEEPSEEK_API_KEY')}"}
    total = 0
    for p in prompts:
        body = {"model": "deepseek-chat", "messages": [{"role": "user", "content": p}]}
        data = requests.post("https://api.deepseek.com/v1/chat/completions", headers=headers, json=body).json()
        total += data["usage"]["total_tokens"]
    return total
