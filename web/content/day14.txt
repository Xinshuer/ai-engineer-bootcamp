title: 项目怎么拆：五个文件，三种数据
--- body
真实项目不会把所有代码写在一个函数里，而是按「一个文件只做一件事」来拆。mini 版和 Clause Check 用同样的文件名：

- `models.py`：数据长什么样（`Clause`、`Verdict`、`ClauseReview`）
- `split.py`：读文件、拆条款。纯代码，不调模型
- `review.py`：**唯一**调模型的地方：发请求、校验、重试
- `pipeline.py`：把前面串起来，汇总，写报告
- `cli.py`：解析命令行参数，调用 pipeline，返回退出码

数据在文件之间这样流动：合同全文 `str` → `list[Clause]` → `list[ClauseReview]` → 报告 `dict` → JSON 文件。**自己产生的数据用 dataclass**（轻，不校验）；**从外面来的数据用 Pydantic**（模型的回答随时可能不合规矩，必须校验）。
--- code
from dataclasses import dataclass, asdict
from typing import Literal
from pydantic import BaseModel

@dataclass
class Clause:              # split.py 产出：自己的数据，不需要校验
    id: str
    heading: str
    text: str

class Verdict(BaseModel):  # 模型的回答：外来数据，必须校验
    clause_id: str
    verdict: Literal["accept", "flag", "redline"]
    risk_level: Literal["low", "medium", "high"]
    topic: str
    rationale: str

@dataclass
class ClauseReview:        # review.py 产出，pipeline.py 汇总
    clause_id: str
    verdict: str
    risk: str
    tokens: int

c = Clause("8.1", "Cap on Liability", "Customer's liability shall be unlimited.")
raw = '{"clause_id": "8.1", "verdict": "redline", "risk_level": "high", "topic": "liability_cap", "rationale": "no cap"}'
v = Verdict.model_validate_json(raw)
r = ClauseReview(c.id, v.verdict, v.risk_level, 180)
print(c)
print(v.verdict, v.risk_level)
print(asdict(r))

title: 从小到大：先让一条跑通
mock: yes
--- body
最容易失败的做法：一口气写完五个文件再运行，然后对着一屏报错不知道从哪查起。

正确的顺序：

1. 先写死**一条**条款，走完「调模型 → 校验 → 打印」，亲眼看到正确的结果
2. 跑通了，再换成循环，跑三条
3. 再一块一块加：重试、汇总、写报告、命令行参数

每加一块就运行一次。这样出错时，你只需要看**刚加的那几行**。今天的 P1–P7 就是按这个顺序排的。

今天所有审查请求都带着第 12 天的 `"thinking": {"type": "disabled"}`：逐条审查用不着长推理，关掉思考模式更快、更便宜，`temperature` 也重新起作用。
--- code
import os
import requests
from typing import Literal
from pydantic import BaseModel

API_URL = "https://api.deepseek.com/v1/chat/completions"
HEADERS = {"Authorization": f"Bearer {os.getenv('DEEPSEEK_API_KEY')}"}

class Verdict(BaseModel):
    clause_id: str
    verdict: Literal["accept", "flag", "redline"]
    risk_level: Literal["low", "medium", "high"]

def review_one(clause_id, text):
    body = {
        "model": "deepseek-flash",
        "messages": [{"role": "user", "content": f"Review clause {clause_id}: {text}"}],
        "response_format": {"type": "json_object"},
        "thinking": {"type": "disabled"},
    }
    data = requests.post(API_URL, headers=HEADERS, json=body, timeout=60).json()
    return Verdict.model_validate_json(data["choices"][0]["message"]["content"])

# 第 1 步：写死一条，先看到结果
print(review_one("8.1", "Customer's liability shall be unlimited."))

# 第 2 步：一条跑通了，再换成循环
for cid, text in [("3.1", "Fees are payable within thirty days."), ("4.2", "Renews for twenty-four (24) months.")]:
    v = review_one(cid, text)
    print(cid, v.verdict, v.risk_level)

@@ concept
title: 校验放在「门口」
--- body
程序的数据从三个门口进来：**文件**（可能不存在、是空的）、**模型的回答**（可能不是 JSON、值不合法）、**命令行参数**（可能拼错）。

在门口检查一次：不合格就立刻报一个说得清楚的错（或者让模型重答）。进了门的数据就是可信的，里面的函数不用再到处写 `if`。

- 文件：`read_contract` 里检查，报 `FileNotFoundError` / `ValueError`
- 模型：`review_clause` 里用 Pydantic 校验，失败就把错误告诉模型，让它再答一次
- 参数：argparse 的 `choices` 替你检查

常见错误：模型的回答不校验就往下传，直到 `summarise` 排序时才因为一个 `"HIGH"` 报 `KeyError`，这时离真正出错的地方已经很远了。
--- code
import argparse
import json
from typing import Literal
from pydantic import BaseModel, ValidationError

class Verdict(BaseModel):
    verdict: Literal["accept", "flag", "redline"]
    risk_level: Literal["low", "medium", "high"]

RISK_RANK = {"high": 0, "medium": 1, "low": 2}
raw = '{"verdict": "flag", "risk_level": "HIGH"}'   # 模型写成了大写

# 不在门口校验：到排序时才出错，离原因很远
try:
    RISK_RANK[json.loads(raw)["risk_level"]]
except KeyError as e:
    print("summarise 里才发现:", repr(e))

# 在门口校验：一拿到回答就知道哪里不对
try:
    Verdict.model_validate_json(raw)
except ValidationError as e:
    print("review 里就发现:", e.errors()[0]["loc"], e.errors()[0]["msg"])

# 命令行参数：choices 就是门口的检查
parser = argparse.ArgumentParser(prog="minicheck")
parser.add_argument("--only-risk", choices=["low", "medium", "high"])
try:
    parser.parse_args(["--only-risk", "urgent"])
except SystemExit as e:
    print("argparse 拒绝了，退出码", e.code)

from pathlib import Path

def read_contract(path):
    p = Path(path)
    if not p.exists():
        raise FileNotFoundError(f"contract not found: {path}")
    text = p.read_text(encoding="utf-8")
    if not text.strip():
        raise ValueError(f"contract is empty: {path}")
    return text

import re
from dataclasses import dataclass

HEAD = re.compile(r"^(\d+(?:\.\d+)*)\.?\s+([A-Z].*)$")

@dataclass
class Clause:
    id: str
    heading: str
    text: str

def split_clauses(text):
    clauses = []
    current = None
    for line in text.split("\n"):
        m = HEAD.match(line.strip())
        if m:
            current = Clause(m.group(1), m.group(2), "")
            clauses.append(current)
        elif current is not None:
            current.text += line + "\n"
    for c in clauses:
        c.text = c.text.strip()
    return [c for c in clauses if c.text]

--- prompt
**项目第 3 块（review.py）的前半。** `call_model(messages)` 把 messages 发给模型、要求 JSON 格式，返回**整个**回答字典（后面既要读 `content`，也要读 `usage`）：

- 200：返回 `resp.json()`
- 429 / 500 / 503：重试，一共最多 `max_attempts` 次
- 其他状态码（400、401）：不重试，直接 `raise RuntimeError`
- 次数用完：`raise RuntimeError`

填空。这是第 4 天的重试，现在成了项目的一块。
--- template
import os
import requests

API_URL = "https://api.deepseek.com/v1/chat/completions"
RETRYABLE = (429, 500, 503)

def call_model(messages, max_attempts=3):
    headers = {"Authorization": f"Bearer {os.getenv('DEEPSEEK_API_KEY')}"}
    body = {"model": "deepseek-flash", "messages": messages, "response_format": {"type": "json_object"},
            "thinking": {"type": "disabled"}}
    for _ in range([[max_attempts]]):
        resp = requests.post(API_URL, headers=headers, json=body, timeout=60)
        if resp.status_code == 200:
            return [[resp.json()]]
        if resp.status_code [[not in]] RETRYABLE:
            raise RuntimeError(f"API error {resp.status_code}")
    [[raise]] RuntimeError(f"gave up after {max_attempts} attempts")

# ===== review.py =====
API_URL = "https://api.deepseek.com/v1/chat/completions"
RETRYABLE = (429, 500, 503)
SYSTEM = ("You review one contract clause for the customer. Reply with a JSON object only, with the keys "
          "clause_id, verdict (accept|flag|redline), risk_level (low|medium|high), topic, rationale.")

def call_model(messages, max_attempts=3):
    headers = {"Authorization": f"Bearer {os.getenv('DEEPSEEK_API_KEY')}"}
    body = {"model": "deepseek-flash", "messages": messages, "response_format": {"type": "json_object"},
            "thinking": {"type": "disabled"}}
    for _ in range(max_attempts):
        resp = requests.post(API_URL, headers=headers, json=body, timeout=60)
        if resp.status_code == 200:
            return resp.json()
        if resp.status_code not in RETRYABLE:
            raise RuntimeError(f"API error {resp.status_code}")
    raise RuntimeError(f"gave up after {max_attempts} attempts")

def review_clause(clause, call=call_model):
    messages = [
        {"role": "system", "content": SYSTEM},
        {"role": "user", "content": f"Review clause {clause.id}: {clause.text}"},
    ]
    tokens = 0
    for _ in range(2):
        data = call(messages)
        tokens += data["usage"]["total_tokens"]
        content = data["choices"][0]["message"]["content"]
        try:
            v = Verdict.model_validate_json(content)
        except ValidationError as e:
            messages.append({"role": "assistant", "content": content})
            messages.append({"role": "user", "content": f"Invalid reply: {e.errors()[0]['msg']}. Reply with the JSON object only."})
            continue
        return ClauseReview(clause.id, v.verdict, v.risk_level, tokens)
    raise RuntimeError(f"clause {clause.id}: no valid JSON after 2 attempts")

from dataclasses import dataclass

RISK_RANK = {"high": 0, "medium": 1, "low": 2}

@dataclass
class ClauseReview:
    clause_id: str
    verdict: str
    risk: str
    tokens: int

def id_key(clause_id):
    return tuple(int(x) for x in clause_id.split("."))

def summarise(reviews):
    counts = {"accept": 0, "flag": 0, "redline": 0}
    for r in reviews:
        counts[r.verdict] += 1
    flagged = [r for r in reviews if r.verdict != "accept"]
    flagged.sort(key=lambda r: (RISK_RANK[r.risk], id_key(r.clause_id)))
    return {
        "clauses": len(reviews),
        "counts": counts,
        "needs_attention": [r.clause_id for r in flagged],
        "tokens": sum(r.tokens for r in reviews),
    }

from collections import defaultdict
from dataclasses import dataclass

RANK = {"high": 0, "medium": 1, "low": 2}

@dataclass
class Finding:
    clause_id: str
    rule_id: str
    severity: str

def id_key(clause_id):
    return tuple(int(x) for x in clause_id.split("."))

def triage(findings):
    by_clause = defaultdict(list)
    for f in findings:
        by_clause[f.clause_id].append(f)
    rows = []
    for cid, fs in by_clause.items():
        worst = min((f.severity for f in fs), key=lambda s: RANK[s])
        rows.append((cid, worst, sorted({f.rule_id for f in fs})))
    rows.sort(key=lambda r: (RANK[r[1]], id_key(r[0])))
    return rows

合同本身就是按条款切好的块。写 `find_clauses(text, query, k)`：

1. **切块**：去掉首尾空白后能匹配 `r"^(\d+(?:\.\d+)*)\.?\s+([A-Z].*)$"` 的行是条款标题，下面直到下一个标题的行是正文；正文为空的标题跳过
2. **分词**：转小写后 `re.findall(r"[a-z0-9]+", ...)`
3. **分数** = query 里**不同的**词出现在正文里的个数 + 2 × 出现在标题里的个数（标题最能说明这一条讲什么）
4. 只保留分数 > 0 的；分数从高到低，同分按编号的数字顺序；返回前 `k` 条的 `(编号, 分数)` 元组列表

import re

HEAD = re.compile(r"^(\d+(?:\.\d+)*)\.?\s+([A-Z].*)$")

def words(text):
    return set(re.findall(r"[a-z0-9]+", text.lower()))

def find_clauses(text, query, k):
    clauses = []
    for line in text.split("\n"):
        m = HEAD.match(line.strip())
        if m:
            clauses.append([m.group(1), m.group(2), []])
        elif clauses:
            clauses[-1][2].append(line)
    q = words(query)
    scored = []
    for cid, heading, lines in clauses:
        body = "\n".join(lines).strip()
        if not body:
            continue
        score = len(q & words(body)) + 2 * len(q & words(heading))
        if score > 0:
            scored.append((cid, score))
    scored.sort(key=lambda s: (-s[1], tuple(int(x) for x in s[0].split("."))))
    return scored[:k]

import os
from typing import Literal
import requests
from pydantic import BaseModel, ValidationError

URL = "https://api.deepseek.com/v1/chat/completions"

class Verdict(BaseModel):
    clause_id: str
    verdict: Literal["accept", "flag", "redline"]
    risk_level: Literal["low", "medium", "high"]

def review(clause_text):
    headers = {"Authorization": f"Bearer {os.getenv('DEEPSEEK_API_KEY')}"}
    messages = [{"role": "user", "content": clause_text}]
    for _ in range(3):
        body = {"model": "deepseek-flash", "messages": messages, "response_format": {"type": "json_object"},
                "thinking": {"type": "disabled"}}
        resp = requests.post(URL, headers=headers, json=body, timeout=60)
        if resp.status_code == 429:
            continue
        if resp.status_code != 200:
            raise RuntimeError(f"API error {resp.status_code}")
        content = resp.json()["choices"][0]["message"]["content"]
        try:
            return Verdict.model_validate_json(content)
        except ValidationError as e:
            messages.append({"role": "assistant", "content": content})
            messages.append({"role": "user", "content": f"Invalid: {e.errors()[0]['msg']}. Reply with the JSON object only."})
    raise RuntimeError("no valid verdict after 3 attempts")

--- prompt
模仿 `evals/run_evals.py` 最后打印的那一行。`cases` 是 `[{"id": ..., "kind": ...}]`，`kind` 可能是 `must_flag`、`trap`、`must_accept` 或别的；`runs` 是 `{用例 id: [每次运行的判定, ...]}`。写 `eval_line(cases, runs)`，返回一行文字，格式（两段之间是两个空格）：

`high-risk recall 0.75  false flags 1/4  flaky: payment-net-30`

- **high-risk recall**：`must_flag` 和 `trap` 用例的所有运行里，判定**不是** `accept` 的比例，两位小数；没有这类运行时算 `1.00`（和 `evals/harness.py` 的 `high_risk_recall` 一样）
- **false flags**：`must_accept` 用例的所有运行里，判定不是 `accept` 的次数 `/` 这类运行的总次数
- **flaky**：几次运行的判定不完全一样的用例 id（任何 kind 都算），按 `cases` 的顺序用 `", "` 连接；一个都没有就写 `-`
- 用例在 `runs` 里没有：当作没跑过，哪一项都不算
--- solution
def eval_line(cases, runs):
    hit = total = false_flags = accept_runs = 0
    flaky = []
    for case in cases:
        verdicts = runs.get(case["id"], [])
        if len(set(verdicts)) > 1:
            flaky.append(case["id"])
        for v in verdicts:
            if case["kind"] in ("must_flag", "trap"):
                total += 1
                if v != "accept":
                    hit += 1
            elif case["kind"] == "must_accept":
                accept_runs += 1
                if v != "accept":
                    false_flags += 1
    recall = hit / total if total else 1.0
    return f"high-risk recall {recall:.2f}  false flags {false_flags}/{accept_runs}  flaky: {', '.join(flaky) or '-'}"
